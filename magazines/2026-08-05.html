Mistral представил Shieldstral: новую 3B модель для модерации мультимодального контента

Mistral's Shieldstral: 3B open-weights model for multimodal moderation

Mistral AI выпустила Shieldstral — небольшую открытую мультимодальную модель размером 3 миллиарда параметров, предназначенную для модерации контента. Эта модель является еще одним шагом к созданию более гибких и настраиваемых систем модерации. Комментаторы задаются вопросом, сможет ли Shieldstral адаптироваться под произвольные наборы правил или же будет придерживаться стандартных подходов крупных техгигантов, а также обсуждают потенциальные предубеждения модели, приводя в пример ее реакцию на тексты Вольтера.

Zero-Mem: Новая архитектура для LLM-агентов с нулевым расходом токенов на память

Zero-Mem: Zero-Token Memory Operations for LLM Agents

Представлена исследовательская работа о Zero-Mem — инновационном подходе к управлению памятью для LLM-агентов, который позволяет обрабатывать запросы без расхода токенов на хранение информации. Это значительно повышает эффективность и снижает стоимость работы с долгосрочной памятью в больших языковых моделях. В комментариях разработчики обсуждают практическую реализацию такой системы, включая использование KV-кэша и локальных LLM для прямого извлечения данных из памяти, что открывает новые возможности для оптимизации агентов.
